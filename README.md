# Meteor-Madness: 2D Asteroids Clone

**Meteor-Madness** is a 2D arcade-style shooter developed as a project for CIS 297 at the University of Michigan-Dearborn. Built using **C#** and the **.NET Framework (Windows Forms)**, the project focuses on applying **Object-Oriented Programming (OOP)** principles to manage game states, coordinate collision detection, and handle real-time object movement. 

## How to Run
To run this project, it is recommended to use **Visual Studio 2022 (Community Edition)** with the **.NET desktop development** workload installed.

1. **Download:** Clone or download the `Meteor Madness` folder.
2. **Open:** Locate and double-click the `Meteor Madness.sln` file to launch Visual Studio.
3. **Build & Play:** Press **F5** or the green "Start" button in the toolbar to compile and run the game.
